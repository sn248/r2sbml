## Overview

`r2sbml` is an R package that provides a lightweight interface to the `libsbml` C++ library via Rcpp. It reads SBML (Systems Biology Markup Language) XML files and lets users query model components (species, parameters, reactions, rules, events, function definitions) and export ODE mass-balances for simulation in R/deSolve, mrgsolve, or nlmixr2/rxode.

## Build & Development Commands

```r
# Install the package from source (requires libsbml on Unix/macOS)
R CMD INSTALL .

# Or from within R
devtools::install()

# After editing C++ source files, regenerate Rcpp exports (do not edit R/RcppExports.R or src/RcppExports.cpp by hand)
Rcpp::compileAttributes()

# Run all tests
devtools::test()
# or
R CMD check .

# Run a single test file
testthat::test_file("tests/testthat/test-convert.R")

# Regenerate documentation from Roxygen comments in .cpp files
devtools::document()
```

## Architecture

### Two-phase API

Most operations require two steps:

1. **`getModel(filename)`** — reads an SBML XML file and returns an R `externalptr` (Rcpp `XPtr<Model>`) to the in-memory libsbml `Model` object.
2. **Query functions** — accept that pointer and return R data structures:
   - `getSpeciesTable()`, `getSpeciesNames()`, `getSpeciesIC()`, `getNumSpecies()`
   - `getParameterTable()`
   - `getReactionTable()`, `getReactionMath()`
   - `getCmtNames()`, `getCmtSizes()`
   - `getRuleMath()`, `getFunctionDefinition()`, `getEventMath()`

`convertReactions(infile, outfile, format)` is the exception — it reads the SBML file itself and writes a ready-to-simulate code file in one call. Supported formats: `"R"` / `"deSolve"`, `"mrgsolve"`, `"nlmixr2"` / `"rxode"`.

### C++ / Rcpp layer (`src/`)

Every public function is defined in its own `.cpp` file and exported via `// [[Rcpp::export]]`. `src/RcppExports.cpp` and `R/RcppExports.R` are auto-generated by `Rcpp::compileAttributes()` — never edit them manually.

`convertReactions.cpp` contains the main conversion logic plus three internal helpers (`writeFileR`, `writeFileMrgsolve`, `writeFileNlmixr2`) that write the simulation code for each target format.

### libsbml linking

- Unix/macOS: libsbml must be installed system-wide (`libsbml5-dev` on Ubuntu, built from source or via macports on macOS). `src/Makevars.in` is populated by `configure` using the output of `src/scripts/cmake_config.sh` and `src/scripts/r_config.sh`.
- Windows: `tools/winlibs.R` downloads pre-built binaries from rwinlib at install time.
- A vendored copy of libsbml headers/cmake modules lives under `src/libsbml-install/` (used during the build).

### Example SBML files (`inst/examples/`)

Several `.xml` files covering different SBML features (simple reactions, assignment rules, algebraic rules, function definitions, delay, multi-compartment, boundary conditions, conversion factors). Tests iterate over all of them.

## Testing

Tests live in `tests/testthat/`. Two test files:
- `test-convert.R` — checks that `convertReactions` produces output with expected landmarks (e.g. `## Solving the model requires desolve package`, `$PROB`, `model <- function`).
- `test-sbml-suite.R` — runs all three output formats against every `.xml` file in `inst/examples/` and verifies output files are created.

When the package is not installed, tests fall back to relative paths (`../../inst/examples/`).
